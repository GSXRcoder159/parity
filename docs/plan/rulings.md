### Align throughput (2026-10-07)
- Ruling: the error renderer gives every catalog message two vars read from the request, `{value}` (the request's value at the error's param, else the id in the path) and `{object}` (the object that id names, by prefix) (`requestVars`, `src/twin/errors.ts`). This is twin code after the freeze that fits neither class (0002 §4.5). It is rendering machinery, like the catalog's existing `{param}`, with one exception: the prefix-to-name table holds 5 names copied from oracle messages (customer, invoice, price, subscription, webhook endpoint). Any other prefix renders `{object}` as "" (no name is guessed; the API's naming is not uniform), and so does a request with no value, e.g. `No such : ''`. No message text changes with it; the messages stay data the align loop seeds. The mechanical pass derives a message template from the oracle with the same function: a literal becomes `{var}` when its value changes across occurrences, or when it is `{value}`, the request's own value at the param. The one-binding and echo rules are unchanged and read call-site vars only. Projected on oracle v1 (plan-only `align`, 2026-10-07; nothing applied until a nightly runs `align --apply` on main), 3 messages become automatic (`resource_missing`, `parameter_unknown`, `unit_amount_too_large`): train L3 60.8→68.8%, L4 12.0→20.0%, held-out L3 59.4→61.6% (the held-out `starting_after` case generalizes) — cost if wrong: messages for request shapes the corpus lacks render a wrong quote, which the held-out gate and the nightly score show
- Ruling: the assisted queue is ordered by the train steps a cluster alone unlocks at L3, not by its divergence count, and a cluster is one object type (field loci) or one error key, not one field. Measured 2026-10-07: five card fields at 427 divergences each took the night's slots and could not unlock a step alone, while error messages that were the only divergence on 100 sequences never reached the queue. A fraud/risk divergence (never shown to the LLM, 0001 R8) holds its step back, so the card cluster ranks by what it can unlock.

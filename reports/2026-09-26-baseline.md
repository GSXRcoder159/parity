  > "stripe-mock is stateless. Data you send on a `POST` request will be validated, but it will be completely ignored beyond that."
  
  ([github.com/stripe/stripe-mock](https://github.com/stripe/stripe-mock)). It answers 200 with a fixture wherever the spec allows. Stripe itself answers 404 for a missing resource, 400 for a state error and 402 for a decline.

On its surface it reaches L1 58.1%, L3 3.4% and L4 0%. ## H1 verdict

**Confirmed.** H1 (plan §1): "best existing twin <80% sequence-level agreement on the stateful/error corpus".
- stripe-mock L4 is 0.0% [0.0–4.2] (88 sequences). The errors stratum is 0.0% [0.0–24.3] L4 at 41.8% L1.
- localstripe L4 is 0.0% [0.0–16.1] on the 20 sequences it can serve. It cannot run any errors, refunds, cancellation, events or proration template.
- The sandbox agrees with itself at 100% L4 [94.0–100.0] on the measured half.

The gap is not noise. The verdict would need an L4 above 80% on some target, and every upper bound here is ≤16.1%. Recording the remaining 432 sequences cannot move it there.

## Reproduce

Anyone with their own sandbox key can re-run this. The exact commands are in [`docs/plan/impl/baselines.md`](../docs/plan/impl/baselines.md). In short:

```sh
# .env: STRIPE_API_KEY=<your sandbox key>; PARITY_DATA_DIR=<private dir for raw recordings>
node src/cli.ts record --target sandbox --seeds 1-20 --chunk 50 --chunk-wait 20   # claimable key: pace further, see above
node src/cli.ts oracle build
docker run --rm -d --name parity-stripe-mock -p 12111-12112:12111-12112 stripe/stripe-mock@sha256:ff32647993847be491e68533e2881c90434fa8d5df40246ee5f7d41253422081
node src/cli.ts bench http://localhost:12111 --oracle "$PARITY_DATA_DIR/oracle.jsonl" --out recordings/<date>/w1-bench-stripe-mock
```

Then `reports/baseline.ts surface` → `bench http://localhost:8420` for localstripe, and `pair` → `compare` for the noise floor. Run localstripe on the same UTC day as the oracle: it uses the wall clock. Raw recordings and every `compare`/`bench` output hold Stripe response values. Keep them out of git (C3).

## CI after the push

The nightly's pushes made GitHub's `ci` workflow fail on main, on both `ae1343c` and `6063354` (runs 36373646380 and 36373677478). Locally, the full suite had 5 failures out of 280: 4 in `twin-invoices` (the send-invoice refusals) and 1 in `twin-proration` (`create_preview`'s errors).

- **Cause.** Each failing test asserted a catalog message as the literal placeholder `"parity: <key>"`: `invoice_pay_voided`, `invoice_void_paid`, `invoice_preview_target_missing` and `invoice_upcoming_deprecated`. The align commit had just seeded those messages with the oracle's text.
- **Why it is the tests' fault.** Seeding messages is the align loop's mechanical job by design (0002 §4.3). The gate scores the twin but does not run the test suite, so the next seeded message would break CI the same way.
- **Fix, in tests only.** The four twin test files (`twin-core`, `twin-invoices`, `twin-proration`, `twin-resources-b`) had 29 message assertions pinned this way. They now compare against `CATALOG[key].message`, which still checks which catalog entry was raised.
- **Result.** The full suite passes at the seeded HEAD (280 tests: 279 pass, 1 live-only skipped), and `tsc` is clean. The twin was not changed.

## Caveats

1. **The published curve point is the pre-align score.** It shows train L3 24.6%. The align commit's 26.8% appears on the next nightly's point.
2. **The noise ceiling covers 60 of 600 sequences**, all 30 templates. The page publishes the overall ceiling because every scored template is covered. Per-stratum ceilings rest on 2–14 pairs at L4.
3. **The slice is a fixed one-seventh.** Decision 0001 C2 (2026-09-27) sizes it as `min(1/7 of the corpus, (10,000 − 1,500 − rolling30) / 7)`, but `src/nightly.ts` uses a fixed `dow/7`. Tonight both give 86 sequences: the allowance was about 706 sequences, and the fixed slice cost 167 GETs.
4. **The patch count includes one net-zero edit** (the max-depth `code`, above). The 80 divergences removed are the batch's.
5. **The gate does not run the test suite.** A mechanical patch is judged only by score-twin. Tests that pin other align-owned data could still break CI after a nightly, as the messages did tonight. Examples are shape-template defaults, which the 174 earlier patches changed without breaking a test. This run found only the messages.
